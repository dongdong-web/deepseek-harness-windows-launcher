# Security Policy

## Supported versions

Security fixes target the latest tagged community release. DeepSeek Harness is
in developer preview, so release compatibility may change quickly.

## Reporting a vulnerability

Do not post exploit details, API keys, access tokens, or personal data in a
public issue. After this repository is created on GitHub, the maintainer should
enable **Private vulnerability reporting** in the repository Security settings;
use that channel for security reports.

Until that channel is enabled, do not disclose a vulnerability publicly. Open
an issue only to request a private reporting channel, without technical details.
